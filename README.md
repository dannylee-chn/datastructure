# 数据结构与算法学习仓库

## 算法与数据结构基础
1. **排序基础**
    - [Mergesort.java](Mergesort.java)：归并排序
    - [Quicksort.c](Quicksort.c)：快速排序
    - [Quicksort2way.c](Quicksort2way.c)：双路快速排序
    - [Quicksort3ways.c](Quicksort3ways.c)：三路快速排序
    - [Quicksort3ways_nopointer.c](Quicksort3ways_nopointer.c)：三路快速排序（无指针）

2. **数据结构基础：动态数组，栈和队列**
    - [Array.java](Array.java)：动态数组
    - [ArrayStack.java](ArrayStack.java)：数组实现栈
    - [ArrayQueue.java](ArrayQueue.java)：数组实现队列
    - [LoopQueue.java](LoopQueue.java)：循环队列

3. **动态数据结构基础：链表**
    - [LinkedList.java](LinkedList.java)：单向链表
    - [LinkedListStack.java](LinkedListStack.java)：链表实现栈
    - [LinkedListQueue.java](LinkedListQueue.java)：链表实现队列

4. **递归，循环不变量：二分查找法**
   - [BinarySearch.c](BinarySearch.c)：二分查找法（递归，非递归，循环不变量）
   - [Binarysearch_.c](Binarysearch_.c)：二分查找法变种：（左右边界，upper，ceil）

5. **二分搜索树🌲**
     - [BST.c](BST.c)：二分搜索树（添加元素，查询元素）
     - [LinkedListMap.c](LinkedListMap.c)：映射（基于链表，实现对文档词频统计）

6. **冒泡排序，希尔排序**
     - [BubbleSort.c](BubbleSort.c)：冒泡排序🫧
     - [ShellSort.c](ShellSort.c)：希尔排序
  
7. **线段树**
    - [SegementTree.c](SegementTree.c)：线段树🌲
